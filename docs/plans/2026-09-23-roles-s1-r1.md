## 1. System overview

relay's roles (builder, reviewer, researcher) are hard-wired in
`internal/harness/harness.go:39-58` (`roleTable`). Each role's candidates and
tier are scattered: `candidates.json` (`roles`, `tier` per candidate) and
`policy.json` (`order`, `tier` per role). This round builds the data model
that replaces them: a `Registry` of roles, loaded from an optional
`roles.json` or derived from the legacy fields. It answers four questions:
- which roles exist;
- which definition a role runs on a harness kind;
- which candidates a role uses, ranked;
- which tier a role runs at.

Nothing uses it yet.

## 3. Data structures

### 3.1 `internal/roles/file.go`

`File`: the decoded `roles.json`.
- `Rows map[string]Row`: keyed by role name. The role name must match
  `^[a-z][a-z0-9-]{0,31}$`.
- `Unknown []string`: sorted dotted paths of every JSON key the schema doesn't
  know, e.g. `builder.colour`, `builder.definitions.claude.model`. Kept for
  round 3's doctor warning. Never an error.

`Row`: every field is optional, and a pointer or nil-able so that "absent" can
be told apart from "zero".
- `Shape *string`, JSON `shape`: `"writer"` or `"reader"`.
- `Gate *bool`, JSON `gate`.
- `Definitions map[string]DefRow`, JSON `definitions`: harness kind → row.
- `Candidates []string`, JSON `candidates`. nil = absent; an empty list is
  allowed and means "no candidates".
- `Tier *string`, JSON `tier`.

`DefRow`:
- `Agent string`, JSON `agent`: required.
- `Requires []string`, JSON `requires`: optional.

`ErrBadRoles = errors.New("bad roles")`: exported sentinel.

### 3.2 `internal/roles/registry.go`

`Definition`: the resolved definition of one role on one kind.
- `Agent string`
- `Requires []string`
- `Custom bool`: false exactly when `Agent` and every `Requires` name are
  shipped names for that kind (`harness.IsShipped`).

`Ranked`:
- `Token string`: canonical `harness/provider/model`.
- `Position int`: 1-based index in the list it came from, or 0 for
  "unlisted, after order" (legacy only).

`Role`:
- `Name string`
- `Shape harness.RoleShape`: `harness.ShapeBuilder` for writer,
  `harness.ShapeConsult` for reader.
- `Gate bool`
- `Builtin bool`
- `Candidates []string`: tokens as written. `order[R]` in legacy mode (nil
  when absent), the row's `candidates` in file mode.
- `Ranked []Ranked`: see §5.2 and §5.3.
- `Ordered bool`
- `Definitions map[string]Definition`: kind → resolved definition, only for
  kinds the role can run on.

`Registry`: opaque struct. Its fields are unexported: the roles by name, the
name order, the source, and the candidate set and policy it was built from
(needed by `Serves` and `TierFor` in legacy mode).

`ErrNoDefinition = errors.New("role has no definition for this harness kind")`.

Source constants: `SourceFile = "roles.json"`, `SourceLegacy = "legacy"`.

## 4. Interface definitions

### 4.1 `internal/harness/definition.go`

`func IsShipped(kind, name string) bool`
- True when `Lookup(kind)` succeeds and `h.Role(name)` finds a row. An
  unknown kind gives false.

`func DefinitionPath(kind, name string) (string, bool)`
- Returns the home-relative path of the agent definition `name` for `kind`.
  - If `name` is shipped for `kind`: that row's `Path`, exactly (e.g.
    `.claude/agents/plan-executor.md`).
  - Otherwise the per-kind convention:
    - claude: `.claude/agents/<name>.md`
    - opencode: `.config/opencode/agents/<name>.md`
    - agy: `.gemini/config/agents/<name>.md`
    - codex: `.codex/<name>.config.toml`
  - Unknown kind: `"", false`.
- Precondition: `name` already passed the roles name rule. The function
  itself does not validate it.

### 4.2 `internal/roles/file.go`

`func Load(path string) (*File, error)`
- **Missing file:** `nil, nil`.
- **Read error:** wrapped as `read <path>: %w`.
- **Invalid JSON, or a top-level value that isn't an object:**
  `<path>: <err>: %w ErrBadRoles`.
- **Decoding:** unknown keys are **not** an error (no `DisallowUnknownFields`).
  They are collected into `File.Unknown`. The mechanism is the builder's
  choice. One way is to decode each level a second time into
  `map[string]json.RawMessage` and diff the keys against the known sets:
  - row keys: `shape gate definitions candidates tier`;
  - definition keys: `agent requires`.
- **Validation:** every rule in §5.1. The first failure is returned as
  `<path>: <role>.<field>: <reason>: %w ErrBadRoles`, following the
  `policy.Load` style (`internal/policy/policy.go:494-676`). Rows are
  validated in sorted name order and fields in the order of §5.1, so the
  error is deterministic.
- Postcondition: a non-nil `*File` passed every §5.1 rule.

### 4.3 `internal/roles/builtin.go`

`func builtins() map[string]Role` (unexported)
- One `Role` per name in `harness.RoleNames()`, derived from
  `harness.RoleByName`:
  - `Shape` = `spec.Shape`.
  - `Gate` = true when `Shape == harness.ShapeBuilder`, else false.
  - `Builtin` = true.
  - `Definitions`: for every `h` in `harness.All()`:
    `Definition{Agent: spec.Definition, Requires: spec.Definitions[1:], Custom: false}`.
  - `Candidates`, `Ranked`: nil. `Ordered`: false.
- The table is not duplicated: when `roleTable` changes, the built-ins follow.

### 4.4 `internal/roles/registry.go`

`func Build(f *File, set *candidate.Set, pol policy.Policy) (*Registry, error)`
- Precondition: `set` is non-nil. An empty set, e.g. from a missing
  candidates.json, is allowed.
- `f == nil`: legacy derivation (§5.2), `Source() == SourceLegacy`. Never
  returns an error.
- `f != nil`: file derivation (§5.3), `Source() == SourceFile`. Error: a row's
  `tier` above `pol.MaxTierOrDefault()` gives `roles.json: <role>.tier: <t>
  exceeds max_tier <m>: %w ErrBadRoles`.

`func (r *Registry) Names() []string`
- The built-in names in `harness.RoleNames()` order, then the file's new role
  names, sorted. Returns a copy.

`func (r *Registry) Role(name string) (Role, bool)`
- Returns a deep copy, so callers cannot mutate the registry.

`func (r *Registry) Spec(name, kind string) (harness.RoleSpec, error)`
- Unknown role: `unknown role %q: %w` wrapping `ErrNoDefinition`. Round 2
  maps this to `relay.ErrUnknownRole` at the call site.
- No definition for `kind`: `role %q has no definition for %s: %w
  ErrNoDefinition`.
- Otherwise: `harness.RoleSpec{Name: name, Shape: role.Shape, Definition:
  d.Agent, Definitions: append([]string{d.Agent}, d.Requires...)}`.
- For a built-in role with no file override, the result is `reflect.DeepEqual`
  to `harness.RoleByName(name)`, on every kind.

`func (r *Registry) Serves(name string, ref candidate.Ref) bool`
- False if `Spec(name, ref.Harness)` errors.
- File mode: true iff `ref.String()` is in the role's `Candidates`.
- Legacy mode: true iff the set has the candidate (`set.Lookup(ref)`) and
  `c.Serves(name)`.

`func (r *Registry) TierFor(name string, c candidate.Candidate) (harness.Tier, bool)`
- Implements spec §4.1 without the explicit flag. The explicit flag stays at
  the call site.
- File mode: the role's parsed `tier`, if set.
- Legacy mode: exactly the middle of today's chain (`internal/relay/tier.go:20-35`):
  - `c.Tier` if non-empty and it parses;
  - else `pol.TierFor(name)`;
  - else `"", false`.

`func (r *Registry) Source() string`

## 5. High-level pseudocode

### 5.1 Load validation, per row, in this order

```
for name in sorted(rows):
  require name matches ^[a-z][a-z0-9-]{0,31}$              else "<name>: bad role name"
  builtin := harness.RoleByName(name)
  shape:
    if builtin exists:
      if row.Shape set and row.Shape != shapeWord(builtin.Shape) -> "<name>.shape: built-in role is <word>"
    else:
      require row.Shape set                                  else "<name>.shape: required for a new role"
      require row.Shape in {writer, reader}                  else "<name>.shape: must be writer or reader"
      if row.Shape == writer -> "<name>.shape: a new writer role needs relay send --role, not yet available"
  (a set Shape on a built-in row must also be writer|reader, else the same "must be" error)
  gate:
    if row.Gate == true and effective shape is reader -> "<name>.gate: a reader role has no gate"
  definitions:
    for kind in sorted(row.Definitions):
      require harness.Lookup(kind)                           else "<name>.definitions.<kind>: unknown harness (known: ...)"
      require agent != ""                                    else "<name>.definitions.<kind>.agent: required"
      require agent matches ^[a-z0-9][a-z0-9._-]{0,63}$      else "<name>.definitions.<kind>.agent: bad name %q"
      for each requires[i]: same name rule                   else "<name>.definitions.<kind>.requires[i]: bad name %q"
  candidates:
    for i, tok: require candidate.ParseRef(tok) ok           else "<name>.candidates[i]: <parse err>"
                require not a duplicate                      else "<name>.candidates[i]: duplicate token %q"
  tier:
    if set: require harness.ParseTier ok                     else "<name>.tier: <err>"
```

`shapeWord(ShapeBuilder) = "writer"`, `shapeWord(ShapeConsult) = "reader"`.

### 5.2 Legacy derivation (`f == nil`)

This must reproduce `rankedList` (`internal/relay/candidate.go:108-139`)
exactly. Read it before writing this.

```
for name in harness.RoleNames():
  role := builtins()[name]
  order := pol.OrderFor(name)
  role.Candidates = order          // nil when absent
  role.Ordered = len(order) > 0
  seen := {}
  for i, tok in order:
    ref, err := candidate.ParseRef(tok);  if err: continue
    c, err := set.Lookup(ref);            if err: continue
    if !c.Serves(name):                   continue
    if seen[tok]:                         continue
    seen[tok] = true
    role.Ranked += Ranked{tok, i+1}       // index counts skipped tokens, as "order #N" does today
  for c in set.ForRole(name):             // sorted by ref
    if seen[c.Ref().String()]: continue
    role.Ranked += Ranked{c.Ref().String(), 0}
```

Legacy mode has no new roles. `candidate.Load` accepts only built-in names in
`roles`.

### 5.3 File derivation (`f != nil`)

```
roles := builtins()
for name, row in f.Rows:
  base := roles[name] if built-in, else Role{Name: name, Shape: ShapeConsult, Gate: false, Builtin: false, Definitions: {}}
  if row.Gate != nil: base.Gate = *row.Gate
  for kind, d in row.Definitions:
    base.Definitions[kind] = Definition{d.Agent, d.Requires,
        Custom: !(IsShipped(kind, d.Agent) && all IsShipped(kind, r) for r in d.Requires)}
  if row.Candidates != nil: base.Candidates = row.Candidates
  if row.Tier != nil: parse it; if above pol.MaxTierOrDefault() -> ErrBadRoles (see §4.4); store it
  roles[name] = base
for every role (built-ins without a row included):
  role.Ordered = true
  for i, tok in role.Candidates:
    ref := ParseRef(tok)                                   // already validated by Load
    if set.Lookup(ref) fails: continue                     // tolerated; round 3's `relay policy` warns
    if role has no Definitions[ref.Harness]: continue
    role.Ranked += Ranked{ref.String(), i+1}
```

A built-in role with no `candidates` in the file has `Ranked` empty in file
mode. That's intended: in file mode, `roles.json` is the only place candidates
are assigned. Round 3's `relay roles init` writes every role's list.

Store the parsed tier per role; `TierFor` returns it in file mode.

## 6. Error handling strategy

- `ErrBadRoles`: every `roles.json` validation failure, and the `max_tier`
  check in `Build`. Not recoverable, but reported: callers (round 2) treat it
  exactly as a bad `policy.json` is treated today.
- `ErrNoDefinition`: from `Spec`. Recoverable: a round-2 caller turns it into
  a gate or `ErrRoleNotServed`.
- Legacy `Build` never errors. Unknown keys are never errors.
- No logging in this package. It is pure apart from `Load`'s one `os.ReadFile`.
