## F1. Keys are clipped to their column, so the numbers stay aligned

Real output:

```
candidates                        RNDS  DONE  HALT   MED   TTFT  $/RND  COMMITS
  opencode/cline-pass/cline-pass/deepseek-v4.1-flash#high  158   99%    1%    6m   2.5s  $0.07      0.9
  claude/anthropic/sonnet           69  100%    0%   12m   2.8s  $3.84      2.5
repos                            RNDS    COST  HALT  RNDS/LAND
  https://github.com/fuad-daoud/relay 139   $9.26     1        1.7
```

The key column is a fixed width, but keys longer than it push every number right.

**Change**, in `internal/stats/render.go`:
- The scorecard key (the displayed name, plus ` *` when `Few`) and the repo/feature key
  are fitted to exactly their column's width.
  - A key that fits is padded.
  - A longer candidate key is clipped from the **right**, with a trailing `…`.
  - A repo key is clipped from the **left**, with a leading `…`, so the repo name at
    the end stays visible.
  - The ` *` marker is always kept: clip the name part, then append ` *`.
- `https://` and `http://` are stripped from repo keys **before** fitting.
  `https://github.com/fuad-daoud/relay` becomes `github.com/fuad-daoud/relay`.
- Widths are measured in runes. The keys are ASCII in practice, but `…` is one rune
  and must count as one.

**Tests:**
- A `render_test.go` case with a 55-character token, a repo URL longer than the
  column, and one short key. Every data line's `RNDS` value ends at the same column
  as the header's `RNDS`.
- Regenerate `report.golden` only if its fixture changes. It should not, because its
  keys are short.

## F2. Token totals use `k`, `M` and `B`

The first line printed `1195.0M tok`. `usage.ShortTokens` stops at `M`.

**Change:** add a local `shortTokens(n int64) string` in `internal/stats/render.go`
and use it for the first line instead of `usage.ShortTokens`:
- under 1,000: plain;
- under 1e6: `%.1fk`;
- under 1e9: `%.1fM`;
- otherwise: `%.1fB`;
- strip a trailing `.0`, so `1.0B` becomes `1B`.

Do **not** change `usage.ShortTokens`. Other surfaces print it, and their goldens would
move.

**Test:** a `shortTokens` table covering 999, 1500, 2,000,000, 1,195,000,000 and
1,000,000,000.
