## 4. Contracts

### 4.1 `bind` absorbs `add` and `fork`

`relevo bind` takes the **union** of today's `cmdBind`, `cmdAdd` and `cmdFork` flags. The
placement is chosen by flags:

| flags | behaviour today's code runs |
|---|---|
| none of the below | `cmdBind`'s path (bind the current tree) |
| `--worktree` (new bool), or any of `--cwd DIR`, `--branch B`, `--server S`, `--base REF` | `cmdAdd`'s path with those flags; `--worktree` alone = `add`'s default own-worktree |
| `--from SRC[@ROUND]` | `cmdFork`'s path: SRC is fork's source name, ROUND is fork's `--round` (default: fork's current default when @ROUND is absent), and `--name` is the NEW binding's name (fork's `--new-name`) |

- `--from` combined with `--worktree`/`--cwd`/`--branch`/`--server`/`--base` keeps fork's own
  `--cwd` meaning; if fork refuses a combination today, keep that refusal.
- `--from` together with `--resume`/`--rebind`: exit 2 "--from cannot be combined with
  --resume/--rebind".
- `--resume`/`--rebind` stay bind-only; with a placement flag they exit 2 with the same kind of line.
- Every flag of the three verbs keeps its name, default and help text, except fork's
  `--new-name` (gone; `--name` now) and fork's source `--name` (gone; now in `--from`).
- Implement by keeping `cmdAdd`/`cmdFork` bodies as unexported helpers that `cmdBind` calls
  after parsing. **Do not duplicate their logic.**
- Output lines are unchanged. Where a line names `relevo add`/`relevo fork` in a hint, it becomes
  the `bind` form.

### 4.2 `show` absorbs `diff` and `log`

`relevo show [name] [--round N] [--plan|--report|--diff|--drift|--log|--transcript] [--json]`
gains:

| flag | meaning |
|---|---|
| `--stat`, `--anchors` | valid with `--diff`/`--drift`; exactly `cmdDiff`'s `--stat`/`--anchors` |
| `--follow`, `--after N` | valid with `--log`; exactly `cmdLog`'s |

- `show --log` **without** `--round` prints the binding's whole log exactly as `relevo log`
  printed it, including its `--json` NDJSON form. With `--round` it keeps show's per-round form.
- `show --diff` without `--round` = `relevo diff`'s default round.
- Implement by routing to today's `cmdDiff`/`cmdLog` bodies as helpers. **The output must be
  byte-identical** to `relevo diff …` / `relevo log …` for the same arguments.
- An invalid combination (`--stat` without `--diff`/`--drift`, `--follow` without `--log`)
  exits 2 naming the pair.

### 4.3 `unbind` absorbs `gc`

`relevo unbind <name> [--archive] [--force] | --pick` is unchanged, and gains
`relevo unbind --done [--delete] [--dry-run]`, which is exactly `cmdGC` with those flags. `--done`
with a name or with `--pick` exits 2.

### 4.4 `pause` is removed

- Remove the `pause` dispatch case, `cmdPause`, and its usage line.
- In `internal/relevo`, delete `Pause`, and any function or type that **only** `Pause` uses, only
  if nothing else references it: check with `grep`, and list what you deleted.
- `store.StatePaused` and any code that reads a paused binding **stay**: existing data can hold
  that state, and `bind --resume` restores it.

### 4.5 `status --line` replaces `statusline`

`relevo status --line` is exactly today's `cmdStatusline`: the same output, `COLUMNS`,
`RELEVO_STATUSLINE_MARGIN`, and the same planner filtering. `--line` with `--json`/`--all`/`--name`
exits 2. Remove the `statusline` case.
