## 1. System overview (this is also the design record; the README section restates it)

When a plan splits work across two bindings -- one writes the contract,
another builds against it -- the planner sits in the middle of every
handoff: wait for the report, read it, `relay send --name other --file …`.
An **edge** lets the planner declare that handoff up front: *when this
binding's round N closes and artifact A exists, deliver prompt P to target
T.* Relay never inspects the artifact; it checks existence (the same fact
`queueReport` checks for the report) and delivers a prompt the planner
wrote ahead of time. `queue` (default) puts the handoff in front of the
planner as a held payload with the exact command to run; `fire` runs the
send itself, unattended -- for chains the planner has run before.

**Declaration.** `relay edge add <source> --when <artifact> --then send --target <binding> --prompt <file> [--mode queue|fire] [--round N]`
records `Edge{ID, Round (default: source's current round), When, Then, Target, Prompt (absolute path, must exist), Mode}`
on the **source** binding. `relay edge list <source>`, `relay edge rm <source> <id>`.
`When` ∈ `report | diff | done | gate` (paths: ReportPath, DiffPath, DonePath, GateLogPath). `Then` is `send` only in this round
(`ask` is a follow-up: say so in README).

**Evaluation.** In the daemon, right after the source's round closes
(`queueReport` returned; `closedRound` known -- the same hook point the
verify consult uses), for every edge with `Round == closedRound` and
`!Fired`: artifact exists? no -> leave it (it may appear later this tick
cycle? no: at close the round's artifacts are final; mark `Fired` with
`Result: "skipped: no <artifact>"`). yes -> `queue`: `Queue()` a
`KindEdge` entry `DirToPlanner` with Payload
`relay: edge <id> · <source> round N <when> is ready · run: relay send --name <target> --file <prompt>` (the existing held/pull/prompt delivery carries it to the planner);
`fire`: `Send(ctx, rt, target, prompt, SendOptions{})` from a goroutine-free
call after the source's lock is released (the target has its own lock; a
`Send` inside the source's `WithLock` would nest locks -- so `fire` is
recorded as `Pending` under the lock and executed by the daemon right
after the source's transaction commits, on the same tick); a failed fire
(target busy, gone, gated) is downgraded to a `queue` payload whose text
names the failure. Either way the edge is marked `Fired` with the result
and the time; an edge fires once.

**Bias.** Default `queue`; `fire` per edge. Relay makes no judgement
about the artifact. Builders never declare edges (the CLI is the
planner's).

```
// internal/store/types.go
type Edge struct {
    ID      string    `json:"id"`      // 6 hex, random
    Round   int       `json:"round"`   // the source round whose close is watched
    When    string    `json:"when"`    // report | diff | done | gate
    Then    string    `json:"then"`    // send
    Target  string    `json:"target"`  // binding name
    Prompt  string    `json:"prompt"`  // absolute path to the plan file to hand over
    Mode    string    `json:"mode"`    // queue | fire
    AddedAt time.Time `json:"added_at"`
    Fired   bool      `json:"fired,omitempty"`
    FiredAt time.Time `json:"fired_at,omitempty"`
    Result  string    `json:"result,omitempty"` // "queued" | "sent round N" | "skipped: no report" | "fire failed: <err>; queued"
}
Binding.Edges []Edge `json:"edges,omitempty"`
```

## 5. Pseudocode

Covered by §4. Order at close: report queued -> verify hook -> edges
evaluated (queue payloads queued under the same lock; fire edges armed) ->
delivery -> Save -> Daemon runs armed fires.

## 6. Error handling

- A fire that fails never blocks the source's round or tick; it becomes a
  queued payload naming the failure.
- `AddEdge` refuses everything it can check up front (target missing,
  prompt unreadable, bad round) so a mis-declared edge never silently
  no-ops.
- An edge on a binding that is later unbound is gone with it; an edge whose
  target is unbound by fire time fails -> queued payload.
