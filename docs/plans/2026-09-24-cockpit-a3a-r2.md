# Cockpit A3a, round 2: the baseline revision records the pre-write version

Round 1 is on this branch (commit `fe58429`). It was verified. This round fixes one
gap in the round-1 plan: `record(t, before, extra)` gave no way to pass the config
version **before** the write, so the baseline row stores the post-write version
(`internal/config/revision.go:67-78`). A baseline is "the config as it was before
revisions", and its `version` must be the version that config had.

**Do only this fix. If it is impossible as written or contradicts the code, stop and
report. Do not improvise.**

## Change

1. Replace the `before Doc` parameter of `record` with
   `before snapshot`, where

   ```
   type snapshot struct{ doc Doc; version int64 }
   ```

   Add `func readSnapshot(t *db.Tx) (snapshot, error)`: `readDoc(t)` plus
   `t.ConfigVersion()`, both read at the start of the same Tx.
2. Every caller that reads `before` with `readDoc` at the start of its Tx calls
   `readSnapshot` instead. That covers `Put`, `Delete`, `PutDoc`, `PutSecret`,
   `SecretDelete`, `ImportFiles` and `Rollback`.
3. In `record`:
   - the baseline row uses `before.version` and `before.doc`;
   - the new revision row uses `t.ConfigVersion()` read after the write, as now;
   - `DiffDocs(before.doc, after)` is unchanged.
4. **Test:** extend `TestFirstRevisionAddsBaseline`. Seed with raw `ConfigPut`s so
   the version is, say, 2, then `Put` through the Store (the version becomes 3).
   Assert the baseline `version == 2` and the new row `version == 3`.
5. **Mutation check:** make the baseline use the post-write version again. The
   extended test must fail. Report it, then revert.
6. Run `make check`. Report `git diff --stat`, which must touch only
   `internal/config/**`.
