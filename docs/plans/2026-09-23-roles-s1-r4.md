## 1. System overview

The pattern is the one rounds 2-3 used:
- **`XFor(reg, ...)`** is the new registry-aware function, called by
  production.
- **In legacy mode** (`reg.Source() == roles.SourceLegacy`) it returns
  exactly what the old `X(...)` returns. It either calls `X` directly, or
  shares its code with an identical result.
- **In file mode** it renders from `roles.json`.

## 3. Interface definitions

### 3.1 `internal/relay/policy_view.go`

- **Per-role gate filtering, in the legacy functions too:**
  - `RoleRefusals` passes `gatesForRole(gates, role)` to `refusalFromErr`, not
    `gates`.
  - `FormatPolicy` builds each role's `byToken` rows from
    `gatesForRole(gates, role)`, so a reviewer-only gate never shows on a
    builder row.

  Both only differ for gates with `Role != ""`, which exist since round 3 and
  are not in any existing test. If an existing test fails, **stop and
  report**.
- **`func PolicyWarningsFor(reg *roles.Registry, set *candidate.Set, pol policy.Policy) []PolicyWarning`**
  - Legacy: `return PolicyWarnings(set, pol)`.
  - File: for each role in `reg.Names()`, for each `i, tok` in
    `reg.Role(role).Candidates`:
    - `tok` doesn't parse, or isn't configured:
      `PolicyWarning{Role, Index: i, Token: tok, Text: fmt.Sprintf("roles.json %s.candidates[%d] %q is not a configured candidate", role, i, tok)}`;
    - configured, but `reg.Spec(role, ref.Harness)` errors:
      `Text: fmt.Sprintf("roles.json %s.candidates[%d] %q: %s has no definition for %s", role, i, tok, role, ref.Harness)`.

    File mode has no "serves but not listed" warning: the list is the
    assignment.
- **`func RoleRefusalsFor(reg *roles.Registry, set *candidate.Set, pol policy.Policy, gates []ledger.Gate) []RoleRefusal`**
  - Legacy: `return RoleRefusals(set, pol, gates)`.
  - File: the same loop as `RoleRefusals`, but over `reg.Names()`.
    `serving` is the candidates of `rankedRole(reg, set, role)` in order, the
    resolution is `resolveRole(reg, set, gates, "", role)`, and the gates are
    `gatesForRole(gates, role)`.
- **`func FormatPolicyFor(reg *roles.Registry, set *candidate.Set, pol policy.Policy, gates []ledger.Gate, hist history.History, now time.Time, loc *time.Location) string`**
  - Legacy: `return FormatPolicy(set, pol, gates, hist, now, loc)`.
  - File: the same layout as `FormatPolicy`. Share its row rendering
    (`peakText`, gate texts, `<- would pick`, `would refuse:`) rather than
    copying it. Extract an unexported helper if needed, as long as the legacy
    output stays byte-identical. The differences, and only these:
    1. The role header is `<role>  (roles.json)`.
    2. Rows come from `rankedRole(reg, set, role)`. The tag is `order`, or
       `sole` when exactly one row exists. There are no `unlisted` rows in
       file mode.
    3. A role with no rows prints
       `  no candidate listed in roles.json <role>.candidates`.
    4. The pick and refusal come from `resolveRole(reg, set, gates, "", role)`.
    5. The warnings block renders `PolicyWarningsFor(reg, set, pol)`.
    6. The trailing `no policy configured; write ~/.config/relay/policy.json …`
       line is never printed in file mode.
    7. The history block is unchanged.
- **`func LegacyRoleFieldWarnings(reg *roles.Registry, set *candidate.Set, pol policy.Policy) []string`**
  - Legacy mode: nil.
  - File mode: one string per legacy field still set, in this order:
    1. for each ref in `set.Refs()` whose candidate has non-empty `Roles`:
       `candidates.json: <ref>: roles is ignored; roles.json assigns candidates to roles`;
    2. for each ref whose candidate has non-empty `Tier`:
       `candidates.json: <ref>: tier is ignored; set the role's tier in roles.json`;
    3. if `len(pol.Order) > 0`:
       `policy.json: order is ignored; roles.json <role>.candidates orders them`;
    4. if `len(pol.Tier) > 0`:
       `policy.json: tier is ignored; set the role's tier in roles.json`.
  - Pure.

### 3.5 `cmd/relay/doctor.go`

- **`func assembleRoleDefinitions(reg *roles.Registry, set *candidate.Set, kinds []string) map[string][]string`**:
  - for every ref in `set` (nil-safe) and every role in `reg.Names()` with
    `reg.Serves(role, ref)`: add `reg.Spec(role, ref.Harness).Definitions`
    under that kind;
  - for every kind in `kinds` not yet seen: add
    `reg.Spec("builder", kind).Definitions`;
  - sort and de-duplicate per kind, as today.

  `assembleDefinitions(set, kinds)` keeps its signature and its body becomes
  `return assembleRoleDefinitions(legacyRegistryFor(set), set, kinds)`.
  `legacyRegistryFor(set)` is a small unexported helper:
  `roles.Build(nil, set, policy.Policy{})`, with the error discarded, since
  legacy mode never errors. In legacy mode the result equals today's, as the
  existing `doctor_test.go:142,155` tests pin.
- **`func bindPreflightDefs(ctx, env, kind string, adopted bool, defs []string) []string`**:
  today's `bindPreflight` body, with `doctor.WithDefinitions(map[string][]string{kind: defs})`.
  When `defs` is nil it uses `builderDefinitions()`. `bindPreflight(ctx, env,
  kind, adopted)` keeps its signature and calls
  `bindPreflightDefs(..., builderDefinitions())`.
- **`:244`**: `assembleDefinitions(rt.Candidates, kinds)` becomes
  `assembleRoleDefinitions(rt.RoleRegistry(), rt.Candidates, kinds)`.
- **`:309`**: `relay.PolicyWarnings(rt.Candidates, rt.Policy)` becomes
  `relay.PolicyWarningsFor(rt.RoleRegistry(), rt.Candidates, rt.Policy)`.
- **`:312`**: `relay.RoleRefusals(...)` becomes
  `relay.RoleRefusalsFor(rt.RoleRegistry(), rt.Candidates, rt.Policy, relay.Gates(rt))`.
- **New global rows**, appended right after the `policyChecks` line at
  `:309`, following `policyChecks`' shape for global rows (`Group: ""`):
  - one row `Name: "role source"`, `SevOK`:
    - file mode: `Detail: "roles.json"`;
    - legacy: `Detail: "legacy: candidates.json roles, policy.json order and tier"`;
  - one row per `relay.LegacyRoleFieldWarnings(...)` string:
    `Name: "role source"`, `SevWarn`, `Detail: <the string>`,
    `Fix: "delete it; roles.json is the source"`.
