## 1. System overview

A binding that is between rounds for hours or days holds a worktree on
disk and a builder pane in memory (an idle opencode pane is ~800 MB) for
nothing. #179 gave `relay done` the release half (a clean worktree is
removed, the branch survives, `bind --resume` restores it at the same
path: `internal/relay/status.go:778-794`, `bind.go:193-229`), but `done`
ends the binding. `pause` is the third lifecycle state between ACTIVE and
DONE: it refuses while a round is open, refuses a dirty tree unless
`--commit` (which commits everything on the binding branch), removes the
worktree through the existing teardown, closes a **pane** builder's pane
(the third place relay closes a pane -- CLAUDE.md's list and README's
"Panes are yours, always" both gain the exception, because the human
asked), records `State = paused`, and logs `paused`. `relay bind --resume
--name <n>` on a PAUSED binding takes the restore path that already exists
and implies `--rebind` (a fresh builder on the candidate order, or a new
headless endpoint), sets ACTIVE, logs `resumed`; the round number is
unchanged. `gc` ignores PAUSED as it ignores everything but DONE; `unbind`
works on it. Remote bindings have no local worktree or pane, so `pause`
refuses them (`relay done` is the verb there). `--cwd` bindings have
nothing to drop: refused.

```
// internal/relay/pause.go
type PauseOptions struct{ Commit bool }
type PauseResult struct {
    Round        int    // the last completed round (b.Round - 1)
    Branch       string
    Worktree     string // the path that was released
    Committed    string // sha of the --commit commit, "" when nothing was committed
    PaneClosed   string // pane id closed, "" for headless / no pane
    PaneCloseErr string // non-fatal: the pane was already gone or herdr refused
}
var ErrRoundOpen  = errors.New("round is open; wait for it or relay done")
var ErrPauseDirty = errors.New("worktree has uncommitted changes; commit them, or relay pause --commit")
```

## 5. Pseudocode

Covered by §4. Order inside `Pause` is refusals -> dirty/commit -> remove
worktree -> close pane -> state+log+save -> hook. A failure before "remove
worktree" changes nothing; a failure at "remove worktree" changes nothing
(the commit, if any, is on the branch and is not undone -- say so in the
error: `; the --commit commit %s is on %s`).

## 6. Error handling

- Pane close failure is not an error: the pane may already be gone; the
  result says so and names the `herdr pane close` command.
- `CommitAll` returning `("", nil)` (nothing to commit although `Dirty`
  said dirty -- e.g. ignored files) proceeds to the release; if
  `RemoveWorktree` then refuses as dirty, the error surfaces as above.
- `Pause` on an unknown binding -> `store.ErrNotFound` wrapped as the
  other verbs do.
