## Part A: fleet fixes (`internal/ui/view_fleet.go`)

**A1. A column header row.**
- The table's first body line is a header: `NAME ACTOR ON RND STATE NOW SPEND PLANNER
  REPO`. It uses `faintStyle` and bold, and the same widths, gutter and narrow-drop
  rule as the rows, so it always shows exactly the columns the rows show.
- Windowing counts the header as one fixed line that never scrolls.
- The empty and loading bodies have no header.

**A2. SPEND shows money only.**
- `spendCell` (`view_fleet.go:318-323`) currently returns `usage.MoneyShort`, which
  appends `· N tok` and truncates to `$9.40 ·…`. It becomes:
  - `$%.2f` of `Measured + Estimated`, prefixed `~` when `Estimated > 0`, when that
    sum is above 0;
  - else `plan` when `Plan > 0`;
  - else empty.
- Values under a cent print `<$0.01`.
- Put it in a pure func `spendText(s usage.Spend) string` with a table test.

**A3. Grammar.**
- The context line (`view_fleet.go:157`) must read `1 needs you` for one and
  `N need you` for more, as the header does.
- Share one helper between the header and the context line so they cannot drift.

**A4. `/` filters the fleet.**
- `/` opens a one-line filter input below the context row, using the same
  `textinput` as the cmdline, with prompt `/`. While it is open, `Capturing()` is
  true.
- Rows are kept when the text is a case-insensitive substring of any of: `Key()`,
  actor, `candidateText`, `PlannerName`, `CWD`, `Display`.
- `enter` keeps the filter and closes the input. `esc` clears it and closes. While a
  filter is applied, the context line's right side shows `filter "<text>"`, and
  `esc` at the fleet (not capturing) clears it before anything else.
- The cursor and sticky selection work on the filtered rows.
- Keys gains `/ filter`.

**A5. The `rounds` golden goes through the real path.**
- `goldenRoundsModel` (`golden_test.go:174-194`) appends the rounds view onto the
  fleet stack by hand. That is why its breadcrumb reads `fleet › rounds`, which the
  real `:rounds` never produces.
- Build it through the shell instead: `Options.Start = "rounds"` and the first
  statusMsg, or type `:rounds` then enter, so the golden shows `relevo › rounds`.
