## 1. System overview

Today `internal/relay` asks `harness.RoleByName` for a role's launch spec, and
`policy.OrderFor` / `candidate.Set.ForRole` / `candidate.Tier` for its
candidates and tier. After this round, runtime paths ask
`rt.RoleRegistry()`. That is the registry built from `roles.json` when the
file exists, and otherwise the legacy registry derived from the same
candidates and policy. The daemon's config watcher reloads `roles.json`
together with the other two files.

### 4.2 `internal/relay/runtime.go`

### 4.3 `internal/relay/candidate.go`
- `func rankedRole(reg *roles.Registry, set *candidate.Set, role string) []rankedEntry`.
  For each `r` in `reg.Role(role).Ranked`:
  - look up the candidate (`candidate.ParseRef(r.Token)`, then `set.Lookup`);
    skip it if either fails;
  - `Position > 0` gives `rankedEntry{c, HowOrder, r.Position}`;
  - `Position == 0` gives `rankedEntry{c, HowUnlisted, 0}`.

  An unknown role gives nil.
- `func rankedList(set, pol, role)` (`:108-139`): its body becomes
  `return rankedRole(legacyRegistry(set, pol), set, role)`. It stays for
  `policy_view.go`.
- `func resolveRole(reg *roles.Registry, set *candidate.Set, gates []ledger.Gate, token, role string) (Resolution, error)`.
  The body of today's `resolveCandidate` (`:186-240`), with exactly these
  substitutions:
  - explicit token: `!c.Serves(role)` becomes `!reg.Serves(role, ref)`. The
    error text keeps `(its roles: %v)` with `c.Roles` in legacy mode. In file
    mode it prints `(not in roles.json %s.candidates, or no definition for
    %s)` with role and `c.Harness`.
  - `serving := set.ForRole(role)` becomes the candidates of
    `rankedRole(reg, set, role)`, in that order.
  - `len(pol.OrderFor(role)) == 0` becomes `!reg.Role(role).Ordered`.
  - the loop over `rankedList(set, pol, role)` becomes a loop over
    `rankedRole(reg, set, role)`.

  An unknown role (`reg.Role` gives false) is `ErrRoleNotServed` with the
  existing "no configured candidate serves role %q" text. Every other line,
  and every error text, stays byte-identical.

  The "no candidate serves" message names
  `~/.config/relay/policy.json` / `order.%s`. Keep it as is in this round
  (round 3 reworks the text for file mode).
- `func resolveCandidate(set, pol, gates, token, role)`: its body becomes
  `return resolveRole(legacyRegistry(set, pol), set, gates, token, role)`.
  It stays for tests and `policy_view.go`.

### 4.4 `internal/relay/tier.go`

## 6. Error handling

- A bad `roles.json` (`roles.ErrBadRoles`) fails `newRuntime` exactly as a
  bad `policy.json` does. In the daemon watcher it keeps the last good copy
  (the existing `fail` path).
- `Spec` errors at the launch sites wrap the underlying error. For a
  built-in role they can't occur in legacy mode.
- `ask` maps a missing definition to `ErrRoleNotServed`.
- No new sentinels.
