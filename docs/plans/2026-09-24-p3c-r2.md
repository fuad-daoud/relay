# P3c round 2: the drain blocker waits for the exit trailer, not PID==0

Continue from round 1's commit on `relevo/p3c`. The stop rule is unchanged.

**Why:**
- `markerClose` clears `Builder.PID` **without killing** a builder that is still flushing
  (`headless.go:839`). `drainStream` then keeps rendering that round's `NNN-builder.jsonl` into
  its `builder.log` until the next round starts (`headless.go:311-343`).
- Round 1's blocker 2 (`StreamRound == round && PID != 0`) therefore lets the seal pass delete a
  stream the process is still writing to.
- The process exits and the supervisor writes the `relevo-exit:` trailer
  (`internal/proc/proc.go:28-30,142`) only when the builder is really done.

## Change

1. `Sealable(b Binding, round int, streamDrained bool) bool`. Blocker 2 becomes
   `b.Builder.StreamRound == round && !streamDrained`. **PID is no longer consulted.**
2. The seal pass (`tickOne`) computes `streamDrained` only for `round == b.Builder.StreamRound`:
   - true if `BuilderStreamPath(b.Name, round)` does not exist;
   - otherwise true iff its content contains `"\nrelevo-exit:"` **and** `b.Builder.StreamOffset >=`
     its size, meaning the trailer is written and the drain has consumed everything.
   - For any other round, pass `true`.
   - Put this I/O in a small `(s *Store) StreamDrained(b Binding, round int) bool` in seal.go.
3. The trailer literal:
   - use `proc.ExitTrailer` if `internal/store` can import `internal/proc` without a cycle;
   - otherwise use a store constant with a comment naming `proc.ExitTrailer`, plus an **external**
     test (`package store_test` or in `internal/relevo`) asserting that the two are equal.

## Tests

- **`Sealable` table:** the drain row now takes `streamDrained` false → not sealable, true →
  sealable, regardless of PID.
- **`StreamDrained`:** a stream without the trailer is false; with the trailer but an offset
  short of its size, false; with the trailer and the offset at its size, true; no file, true.
- **Mutation:** restore `&& b.Builder.PID != 0` in place of `!streamDrained`, and confirm a named
  test fails (the case of a PID==0 round with the trailer absent). Then revert.
