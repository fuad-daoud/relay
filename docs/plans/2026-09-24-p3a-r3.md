# P3a round 3: decisions on round 2's six failures; then step 3 and the full check

Continue P3a (the plan from round 1, amended by round 2) from where round 2 stopped. Round 2's
work stays. The stop rule is unchanged. These decisions are final:

**B1: reads never create the DB.** `(*Store).db()` splits into two:
- `dbForWrite()`: today's behaviour (MkdirAll + Open);
- `dbForRead()`: if `<root>/relevo.db` does not exist, it returns `(nil, nil)`.

Every read path (`load`, `list`, `readLog`, `readLogAfter`, `pendingForPlanner`, `ViewedAt`) goes
through `dbForRead` and treats `nil` as "no rows", giving today's missing-file results:
`ErrNotFound`, an empty list, `nil` entries, `(zero, false)`.

The one exception is when a legacy `bind.json`/`log.jsonl` is present to import. That is a write,
so importPresent/importAll use `dbForWrite`. The first `Save`/`AppendLog`/import creates the file.

This fixes `TestAddRemoteExistingBranch` and `TestAddRemoteCleansUpLocalBranchOnSaveFailure`
(their `Load` in a 0500 root no longer creates a file). **Do not edit those two tests.**

**B2: the live record is keyed by name alone.** One store root holds one owner until phase 5.
- Edit `003_binding_record.sql` in place (it is unmerged): the unique index becomes
  `UNIQUE (name) WHERE archived_at IS NULL`.
- `RecordPut` upserts on the live row with that name and updates `owner` along with the other
  columns.
- `RecordGet(owner, name)` becomes `RecordGet(name)`. Update the callers and `record_test.go`,
  including the owner-wildcard test, which becomes "a Put with a new owner updates the same row".

This fixes `TestDoneRefusesQueued`. **Do not edit that test.**

**B3: three sanctioned ports.** These assert the absence of `relevo.db`, which is now the store's
own record file:
- `cmd/relevo/read_verbs_test.go:85-87` and `:111-113`;
- `internal/relevo/daemon_test.go:363-365`.

Replace each stat with an assertion that the **ingest mirror** holds no rows: open the DB and check
that `SELECT count(*)` from `binding`, `event` and `round` are all 0, with a DB that does not
exist also passing. Keep the rest of each test.

**B4: one newer-format `bind.json` must not break `List`.**
- `importAll` skips a dir whose bind.json is a newer format: `slog.Warn` once per name per
  process, leave the file, and continue.
- `list()` returns the rest.
- `load(name)` and `importPresent(name)` for that name still return `ErrNewerFormat`. The ported
  daemon test keeps asserting that.
