## 1. System overview

- **#255** `internal/ingest` derives a round's builder from the last
  `pick`/`switch` log entry's note. `parsePickNote` stops the token at
  ` on ` or `:`, but the local pick note is
  `picked <token> for builder: order #1` (`internal/relay/candidate.go:246`
  `ExplainResolution`), so ` for builder` survives into
  `round.builder_candidate` and `relay history --by builder` shows one
  candidate under two keys. The `:` rule also truncates a model's
  `:effort` suffix (`codex/openai/gpt-5.6-terra:high`). And the switch note
  relay actually writes -- `switched builder (<reason>): picked <tok> for
  builder: ...` (`internal/relay/switch.go:62` `switchEntry`) -- has no
  `->`, so `parseSwitchNote` returns `""` and the round silently falls back
  to the binding's current candidate. One rule fixes all three: a candidate
  token never contains a space, so the token is the first
  space-delimited word after `picked `, with one trailing `:` stripped.
- **#235** `cmd/relay` tests `TestDiffCommand` and `TestDiffDriftCommand`
  set `HOME` to a temp dir but not `XDG_CONFIG_HOME`; `userConfigRoot()`
  (`cmd/relay/main.go:266`) prefers `XDG_CONFIG_HOME`, which the developer's
  shell exports, so the tests read the real `~/.config/relay/candidates.json`
  and fail whenever it names a harness the branch does not know. Fix at the
  package level: a `TestMain` that points `HOME`, `XDG_CONFIG_HOME` and
  `XDG_STATE_HOME` at a fresh temp root for the whole package, plus a test
  that pins that `diff` honours `XDG_CONFIG_HOME`.
- **#239 part 1** was fixed by #245 (`relay.Status` degrades when herdr is
  unreachable; `Report.HerdrError` carries the message). What is left is one
  label: `internal/ui/rail.go` `railView` still says `cannot reach herdr —
  see the error above` when `statusMsg.err` is set before the first
  successful poll, but that error can now only come from the store (or the
  serve source), never from herdr. Reword it. Part 2 of #239 (a reader for a
  serve state dir) is out of scope here.

## 4. Interfaces

```
// internal/ingest/outcome.go (unexported, signatures unchanged)
func parsePickNote(note string) string
    precondition: none
    returns "" when note does not start with "picked "
    otherwise: rest = note after "picked "; tok = rest up to the first ' ' (or all of rest);
               if tok ends with ':' strip that one ':'; return tok
    examples:
      "picked claude/anthropic/sonnet for builder: order #1"            -> "claude/anthropic/sonnet"
      "picked opencode/openrouter/z-ai/glm-5.3-flash on host1: spawn"  -> "opencode/openrouter/z-ai/glm-5.3-flash"
      "picked agy/test/m: explicit, policy bypassed"                     -> "agy/test/m"
      "picked codex/openai/gpt-5.6-terra:high for builder: order #2"    -> "codex/openai/gpt-5.6-terra:high"
      "picked opencode/cline-pass/cline-pass/glm-5.3-flash#high on h: s" -> "opencode/cline-pass/cline-pass/glm-5.3-flash#high"
      "picked x/y/z"                                                     -> "x/y/z"
      "nothing picked"                                                   -> ""

func parseSwitchNote(note string) string
    if i := strings.LastIndex(note, "picked "); i >= 0 { return parsePickNote(note[i:]) }
    else: the existing "->" rule, unchanged
    examples:
      "switched builder (exited (code 1) without a report): picked claude/anthropic/sonnet for builder: order #5" -> "claude/anthropic/sonnet"
      "switched a/b/c -> d/e/f"                                                                              -> "d/e/f"   (unchanged)
      "switched builder (reason): cannot switch"                                                             -> ""
```
