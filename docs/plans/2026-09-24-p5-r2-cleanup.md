# P5 round 2: the server cleans up a DONE served binding once its rounds are acked

Continue on the P5 branch after round 1 (one machine DB with owner-scoped stores). Spec §7
("cleanup after ack"). This is the retention fix for contabo, where 63 DONE bindings have
never been collected.

**Stop rule:** if a step is impossible as written or contradicts the code, stop and report. Do not
improvise, and do not bend a test to fit. Tests change only as §8 sanctions.

## 1. System overview

After each server tick, `Server.Tick` (`internal/serve/daemon.go:16-50`, under `s.mu`, after
the per-owner daemon ticks and before `admit`) collects every served binding that is **settled**.
It:
1. archives its record (`relevo.Unbind(ctx, rt, name, true)`: seals every round into
   `round_file` and marks the record archived, per P3d);
2. force-removes its server worktree;
3. deletes its refs from the owner's bare repo.

The client already holds the results. The client acks only after it has absorbed them
(`internal/relevo/remote.go:1195`).

## 4. Contracts

- **`func settled(b store.Binding, now time.Time) bool`** (pure). It is true iff:
  - `b.State == StateDone`, `b.Serve != nil`, no builder process (`b.Builder.PID == 0`), and no
    consult or gate is running;
  - **and** either `b.Serve.AckedRound >= b.Serve.ClosedRound`, or
    `now.Sub(b.UpdatedAt) >= 7*24h`. The second case is the done-before-ack case found by the
    spike: the work reached the client, but no ack was recorded.
- **`func (s *Server) collectSettled(ctx) (int, error)`.** For each owner store and each binding in
  `List()` with `settled`, in this order:
  1. `rt.Git.RemoveWorktree(ctx, b.Serve.BareRepo, b.Worktree, true)`: **force**, because this
     server copy is disposable once settled. A missing worktree is success.
  2. `rt.Git.DeleteBranch(ctx, b.Serve.BareRepo, b.Branch)`, which is idempotent.
  3. `ListRefs(ctx, bare, "refs/relevo/"+b.Name+"/")`, then `DeleteRef` each (`out`,
     `round-<n>`). Tags are per repo; leave them alone.
  4. `relevo.Unbind(ctx, rt, b.Name, true)`, which archives the record.

  Each binding is handled independently: on an error, log it, skip that binding, and carry on
  (the next tick retries). The function returns the count collected.
  **If any of steps 1-3 fails, do not run step 4**, so a failed cleanup is retried with the
  record still live.
- **`(*git.Client) DeleteRef(ctx, dir, ref string) error`**: `git update-ref -d <ref>`; a missing
  ref is success.
- **`(*git.Client) ListRefs(ctx, dir, prefix string) ([]string, error)`**:
  `git for-each-ref --format=%(refname) <prefix>`.
- **Logging:** one `slog.Info("collected settled binding", "owner", label, "binding", name)` per
  binding.
