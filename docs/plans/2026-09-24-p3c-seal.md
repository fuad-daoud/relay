# P3c: a closed round's files become DB rows once nothing reads them; every reader falls back to the DB

Spec: `docs/specs/2026-09-24-db-as-record-design.md` D7, §5, §12. Main is at `80f885c` (P3a: the
store keeps bindings in `<root>/relevo.db`; round files `NNN-*` still live in `<root>/<name>/`).

This plan **refines** the spec's "seal at close". The planner's code map found that a closed
round's files are still read after the close by:
- the verify consult, for up to 10 min (`verify.go:266-310`);
- edges (`edges.go:175-179`);
- repair (`repair.go:42,114`);
- the stream drain, which appends to the closed round's `builder.log` until the next round starts
  (`headless.go:311-343`);
- the server's file route (`serve/rounds.go:335-400`).

So a round **seals lazily**: once none of these can still need it. The binding dir becomes the
spool of rounds that are open or not yet sealed. It is not moved.

**Out of scope for this round:**
- payload wording (the "Report: <path>" lines);
- `wait` printing text;
- the MCP and handoff text.

A later round changes those. Paths stay valid **identifiers**: `Store.ReadFile(path)` resolves a
sealed path from the DB.

**Stop rule:** if a step is impossible as written or contradicts the code, stop and report. Do not
improvise, and do not bend a test to fit. Tests change only as §8 sanctions.

## 1. System overview

- **Migration 004** adds `round_file`: one row per sealed file, holding the file's raw bytes,
  keyed by the binding record and the file's basename.
- **Seal:** each daemon tick, **before** Reconcile, each binding's sealable rounds (§4.3) are
  sealed. Their `NNN-*` files are written to `round_file` and then deleted.
- **Read:** `Store.ReadFile(path)` returns the file if it exists, otherwise the sealed row.
  `Store.RoundFiles(name)` lists both.
- **Every reader** of a round/consult file that could be closed switches from `os.ReadFile`/`os.Stat`
  to these. `ingest.StoreSource`, `ForkState`, archive and serve's file route use them too, so they
  see sealed files exactly as before.

## 4. Contracts

### 4.1 `internal/db/roundfile.go`

```
(t *Tx) RoundFilePut(recordID, name string, round int, body []byte, mtime, now time.Time) error   // upsert
(d *DB) RoundFileGet(recordID, name string) (body []byte, mtime time.Time, ok bool, err error)
(d *DB) RoundFileList(recordID string) ([]string, error)                                       // names, sorted
```

### 4.2 `internal/store/seal.go`

- `func (s *Store) ReadFile(path string) ([]byte, error)`:
  - `os.ReadFile(path)` on success;
  - otherwise, **only** when the error is ErrNotExist **and** path is `<s.root>/<name>/<base>`
    with base matching `^\d{3}-`, look up `RoundFileGet(record(name).ID, base)`;
  - a miss returns the original ErrNotExist error, so callers' `errors.Is(err, fs.ErrNotExist)`
    keeps working.
- `func (s *Store) StatFile(path string) (size int64, mtime time.Time, ok bool, err error)`: the
  same resolution, for `os.Stat` callers.
- `func (s *Store) RoundFiles(name string) ([]string, error)`: basenames in `Dir(name)`, excluding
  dirs and dot-files, united with `RoundFileList`, sorted and de-duplicated.
- `func Sealable(b Binding, round int) bool` (pure). True iff all hold:
  1. `round < b.Round`: the round is closed. Rounds advance only at close (`reconcile.go:529`).
  2. `b.Builder.StreamRound != round` or `b.Builder.PID == 0`: the drain is done.
  3. No `c` in `b.Consults` with `c.Round == round` whose state is still running (use the state
     predicate the consult reconciler uses; `consult.go`).
  4. `b.GateRun == nil` or it is not for this round.
  5. `b.State != StateDone || true`: DONE bindings seal too. Keep this line out; it only records
     that done is not a blocker.

  **If any other in-flight field names a round** (grep `Round int` in `types.go` Binding: for
  example `HaltNotifiedRound`, `ForkedAtRound`, `Serve.*Round`), decide nothing yourself: list it in
  the report and treat it as **not** a blocker.
- `func (t *Tx) SealRound(name string, round int) (int, error)`:
  1. List the `Dir(name)` files whose NNN prefix == round (round files **and** consult files).
  2. Read each one and `RoundFilePut` it: one db.Tx for the round, with the record id from the
     live record.
  3. After commit, `os.Remove` each one (a remove error is logged; the next seal pass retries,
     and the upsert is idempotent).
  4. Return the count.
  5. Non-NNN files (`land-gate.log`) are never sealed.

### 4.3 The seal pass

In `internal/relevo/daemon.go` `tickOne`, inside its `WithLock`, **after** `tx.Load` and **before**
`Reconcile`:

```
for each round r present among Dir(name)'s NNN- files with Sealable(b, r): tx.SealRound(b.Name, r)
```

Errors are logged per binding and never fail the tick. Serve's daemon runs the same `tickOne`, so
server owner roots seal too.

### 4.5 Readers to switch

Each listed `os.ReadFile(<round path>)` → `rt.Store.ReadFile(...)`, and each `os.Stat(<round path>)`
→ `rt.Store.StatFile(...)`. Where a reader takes a `readFile func(string) ([]byte, error)`
(`PushText`), pass `rt.Store.ReadFile`.

## 6. Error handling

| failure | behaviour |
|---|---|
| a seal read or write error | logged per binding; the files stay; the next tick retries |
| a removal failure after commit | logged; the next pass re-puts the same bytes (idempotent) and removes again |
| `ReadFile` on a DB error (not a miss) | that error is returned |
